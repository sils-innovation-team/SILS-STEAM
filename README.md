# SILS STEAM Project Portal (final)

Upload `index.html` and the `assets` folder to GitHub, then enable GitHub Pages (Settings -> Pages -> main / root).

- No login. Anyone can submit; the project is added to Excel with Status = Pending (Flow: SILS SUBMIT).
- To publish a project, open the Excel table and change Status to exactly: Approved. It then shows on the site (Flow: SILS LIST).
- The two flow links are in index.html, inside `const CONFIG`.
